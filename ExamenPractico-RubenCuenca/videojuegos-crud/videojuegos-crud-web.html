📋 Documentación API
OpenAPI / Swagger — Mantenimiento Perfectivo
Base URL: http://localhost:3000
🔐 Header requerido: X-FIS-EPN-KEY: <tu-api-key>
GET /health Estado del servidor
→ 200 OK: { status: "ok" }
Sin body requerido.
POST /events Registrar evento
Body (JSON):
source: string (max 100)
entity: string (max 100)
action: CREATE|UPDATE|DELETE|QUERY
title: string (max 100)
description: string (opcional)
payload: object (opcional)
→ 201: { ok: true }
→ 400: { message: "..." }
GET /events Listar todos los eventos
→ 200: Array de eventos ordenados por fecha ISO-8601
GET /stats Estadísticas por tipo
→ 200: { create, update, delete, query, total }
Perfectivo: incluye query en el total.
GET /events/source/:s Filtrar por source
→ 200: Eventos donde source === :s
